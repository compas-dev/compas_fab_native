# API reference

`compas_fab_native` is a compas_fab backend: you use it through the regular compas_fab
planner API (`set_robot_cell`, `inverse_kinematics`, `check_collision`,
`plan_cartesian_motion`, `plan_motion`, ...). The pages of compas_fab document those calls;
this page covers what is specific to the native backend: its constructor options and the
planner options it understands.
